# leo-agents

一个从零手写、以“一切皆插件”为核心、面向商用的 TypeScript Agent 框架（规划中）。

- 内核借鉴 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的服务 / 事件 / 可撤销副作用插件运行时
- 开发体验与插件分发借鉴 [pi](https://github.com/earendil-works/pi) 的极简扩展与插件包
- 补齐商用能力：多租户、权限与沙箱、计量计费、可观测性、评测

📄 详细设计：[docs/architecture-plan.md](docs/architecture-plan.md)
